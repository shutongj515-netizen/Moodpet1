# MoodPet – Interactive Virtual Puppy

## Project Overview

MoodPet is an interactive virtual pet game developed using Processing Python Mode for my UTS Creative Coding project.

The game allows users to choose a virtual dog, give it a name, and interact with it through different activities. The dog's mood, energy level, and animations change in response to user actions.

## Features

- Five selectable dog breeds: Pug, Border Collie, Pomeranian, Shiba, and French Bulldog.
- Custom dog naming.
- Four interactive actions: Pet, Feed, Play, and Rest.
- Different emotional states, including normal, happy, excited, sad, tired, and resting.
- Energy management system.
- Animated dog movements and changing background colours.
- Automatic mood changes based on inactivity and energy levels.

## How to Run

1. Download the project source code from this repository.
2. Install Processing and select Python Mode.
3. Place the `Moodpet_final.pyde` file inside a folder named `Moodpet_final`.
4. Open the project in Processing.
5. Click the Run button to start the game.

## How to Play

1. Click **Start** on the welcome screen.
2. Choose one of the five available dogs.
3. Enter a name for your virtual pet.
4. Use the interaction buttons to care for your dog.

**Pet:** Makes the dog happy.

**Feed:** Increases the dog's energy.

**Play:** Makes the dog excited and uses energy.

**Rest:** Allows the dog to recover energy.

## Programming Concepts

MoodPet demonstrates several programming concepts:

- **Variables:** Store information about the dog, including its name, mood, and energy.
- **Lists:** Store the available dog breeds.
- **Functions:** Organise different parts of the program, including `setup()`, `draw()`, `mousePressed()`, and `update_pet()`.
- **Conditional Statements:** Determine how the dog responds to user interactions.
- **Event Handling:** Detect mouse clicks and keyboard input.
- **Animation:** Use mathematical functions such as `sin()` to create movement.
- **Time-Based Behaviour:** Use `millis()` to manage mood changes and inactivity.
